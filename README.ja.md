# AI エージェント組織 — 実測報告

[English](README.md)

一人の運用者が、日々の仕事を AI コーディングエージェントの組織 (タスクごとの主セッションがサブエージェントに仕事を振り、結果を確かめる形) で回した実測を、集計値だけでまとめた短い技術報告です。対象期間は 2026 年 10 月です。

- **報告書:** [report.ja.md](report.ja.md) (日本語) · [report.md](report.md) (英語、正本)
- **扱うこと:** 休止後のプロンプトキャッシュの書き直し · 主セッションとサブエージェントのトークンと推定費用の内訳 · 秘密情報・個人情報の検出器の陽性対照と 4 段の公開前関門
- **データ:** [`data/`](data/) の集計済み CSV。セッション単位・日単位・識別につながる行は含みません
- **図:** [`figures/`](figures/)。`scripts/make_figures.py` で `data/` から作り直せます
- **スクリプト:** [`scripts/`](scripts/)。自分のログで走らせれば自分の数値が出ます (報告書の「再現のしかた」)

## 主な数値 (2026 年 10 月、運用者 1 人・機械 1 台)

| | |
|---|---|
| キャッシュ期限切れ後のリクエストの書き込み中央値 | 55,961 トークン (434 件) |
| キャッシュが温かい時のリクエストの書き込み中央値 | 1,268 トークン (83,236 件) |
| 主セッションの書き込みトークンのうち、冷えたリクエストの割合 | 12.1% |
| サブエージェントが占める割合 (リクエスト / 標準単価での推定費用) | 71% / 59% |
| gitleaks・TruffleHog・Presidio を単独で走らせて、どれも報告しなかった合成サンプル | 22 件中 7 件 |

費用は標準単価で換算した概算で、割合だけを示しています。請求の情報は使っていません。
